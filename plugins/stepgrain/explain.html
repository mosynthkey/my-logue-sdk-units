StepGrain

AUDIO IN をモノラルで最大 3 秒ため、タッチでその音を止めて、テンポのグリッドに合わせて粒にして重ねるエフェクトです。粒の長さは STEPS と ENV、出す時刻は STEPS、1 回に何粒出すかとどこから読むかは DENS が決めます。

  1. 1(L+R)/2 をリングへ
  2. 2タッチでフリーズ
  3. 3STEPS ごとに発火
  4. 4ENV の包絡で再生

図1. トリガ、長さ、attack / release

STEPS はトリガの間隔です。音量が 1 の区間も、バッファに収まるときは同じ長さです。ENV はその前後に同じ長さののりしろを足し、前が attack、後ろが release です。要求する全長は本体 + 2 × のりしろです。包絡は smoothstep で、平坦な区間は 1 です。

ENV が Off のとき、のりしろの譜面長は 0 で、実装は各 8 samples です。フリーズしたサンプルでもグリッドを待たず 1 回発火します。その後は STEPS の間隔で、Half は 16 分とその真ん中です。図の時刻 0 は、その等間隔グリッドです。

  • Attack（ENV）
  • Body（STEPS）
  • Release（ENV）
  • Requested（切り詰め前）

図2. DENS と 12 スロット

DENS はパッド X（0〜1023）です。smoothstep したあと、1 回のトリガで出す粒は 1〜6、読み位置のばらつきはバッファ長の ±5%〜±35% になります。同時に鳴る粒は 12 までです。空きが無く、どの粒も寿命の 65% より前なら、その発火は捨てます。65% を過ぎた粒があれば、いちばん進んだものを新しい粒に置き換えます。

音量補正は切り詰め前の比です。overlap = 粒数 × (1 + ENV の 16 分数 / STEPS の 16 分数)、gain ≈ 1.85 / √overlap。ENV Off は比が 0 なので、8 samples ののりしろは音量に入りません。各粒はこの gain に 0.75〜1.10 の乱数を掛けます。

  • Dropped spawn
  • 白い刻み = 寿命の 65%（ここを過ぎると置換可）

図3. グレインの取得

開始位置はステップ番号ではありません。フリーズ窓の 70% を中心に、±spray の一様乱数です。左が古い音、右がタッチ直前です。順方向はその位置から毎サンプル rate だけ進みます。逆方向は、開始を出力のグレイン長だけ先へずらしてから、同じ速さで戻ります。窓の端では先頭へ戻って線形補間します。

rate は OCT（パッド Y）です。Y を 0〜1 として 0〜2 オクターブに直線対応し、隣り合う 2 音（rate 1 / 2 / 4）を確率で混ぜます。中央の 512 はほぼ +1 oct です。REVS はその粒を逆再生にする確率です。定位は SPRD の幅で等パワーに振れます。

録音はフリーズするまで続きます。使える音（2048 samples 以上、ピーク 0.003 以上、離してから 0.25 秒以上）があればタッチですぐ止め、無ければ 0.25 秒録ってから止めます。離すと粒を消して録音に戻ります。出力の MIX / MODE（音量か、原音 LPF + 粒 HPF）はこの図の外です。
